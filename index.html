§1  Main work: physverify

research software · MIT

Does the simulation solve the equations it claims?

physverify checks that a simulation solves the equations it claims, at the order of accuracy it claims, not just that it runs. It runs your solver at several resolutions, measures the error, and gives PASS, FAIL or INCONCLUSIVE with a reason. Convergence-order, conservation and manufactured-solution checks for ODE and 1D PDE solvers; a static scan for Runge-Kutta tables, grid spacings and physical constants. Needs only NumPy.

GitHub PyPI Docs doi:10.5281/zenodo.23534512

Limits: works best for ODEs; PDEs in 1D so far. A PASS means these checks found nothing wrong, not that the simulation is proven correct.
